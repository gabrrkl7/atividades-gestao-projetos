## Observação sobre as premissas

Os PDFs informam o nome dos projetos, os requisitos das atividades e os artefatos de apoio, mas não apresentam uma especificação detalhada do produto FieldOps nem a proposta completa do PII. Por isso, as hipóteses adotadas estão registradas nos arquivos de contexto e identificadas nos artefatos. Elas podem ser substituídas pelos dados reais do grupo sem alterar a estrutura dos documentos.
